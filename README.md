# EcoBot Autonomous Trash Collector

EcoBot is a prototype for an autonomous trash collection robot designed to streamline waste pickup in public spaces and improve environmental cleanliness. This project showcases a multidisciplinary approach combining mechanical design, embedded systems, and intelligent sensing.

## Project Summary

EcoBot integrates:
- autonomous navigation logic for route planning and obstacle avoidance
- AI-based object detection for identifying trash items
- embedded control for motors, sensors, and actuators
- mechanical design for effective trash intake and chassis stability

The repository includes CAD models, electronics design artifacts, and supporting documentation for the robot platform.

## Key Features

- Autonomous path planning and movement control
- Trash detection using computer vision methods
- Hardware-ready embedded system design
- Modular mechanical structure for rapid prototyping
- Focus on real-world usability and environmental impact

## Technical Stack
- Mechanical design: FreeCAD
- Embedded systems: Arduino-compatible microcontroller concepts
- AI / vision: YOLO-style object detection concepts
- Robotics middleware: ROS2 planned for future scalability
- Documentation & design review: KiCad, CAD files, and project notes

## Repository Structure

- `Embeddeds/` – electronics and firmware-related files
- `Mechanicals/` – CAD mechanical design files for the robot chassis
- `assets/references/` – supporting diagrams, reference materials, and design inspiration
